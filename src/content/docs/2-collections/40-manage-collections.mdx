The Collections page is where you see everything qSortBy touches in one place. This guide walks through the source tabs, the status badges, the stat tiles up top, and the row actions you use to run or pause a sort.

## 1. Read the stat tiles and source tabs

![Read the stat tiles and source tabs](/assets/manage-collections/qsortby-collections-manage-step-01.png)

Open **Collections** from the left menu. The tiles across the top summarise how qSortBy is doing — collections managed, average CTR, auto-sorts run, and revenue influenced. Below them, the source tabs split your collections by origin: **All**, **From Shopify**, **From qSortBy**, and **Smart collections**. Start on **All** to see the full list.

<Callout type="tip" title="Tip">
These are mocked preview numbers — your store's real metrics appear once the app is installed.
</Callout>

## 2. Check each collection's status

![Check each collection's status](/assets/manage-collections/qsortby-collections-manage-step-02.png)

Every row carries a status badge so you know what qSortBy is doing with it: **Live** means it's sorting on schedule, **Paused** means sorting is on hold, **Draft** means it isn't set up yet, and **Archived** means it's retired. Scan the badge column to spot anything that needs attention.

## 3. Run or pause from the row menu

![Run or pause from the row menu](/assets/manage-collections/qsortby-collections-manage-step-03.png)

Each row has an overflow menu (the **•••** button) with quick actions. Choose **Run now** to trigger an immediate re-sort, or **Pause** to stop automatic sorting without losing the collection's setup. You can resume any time.

## 4. Create a new collection

![Create a new collection](/assets/manage-collections/qsortby-collections-manage-step-04.png)

When you're ready to add one, select **Create collection** in the top-right. qSortBy walks you through naming it, choosing how products join, and picking the sort rule.

That's the collections list: the tiles tell you how sorting is performing, the tabs and badges help you find any collection fast, and the row menu lets you run or pause a sort in one click.
