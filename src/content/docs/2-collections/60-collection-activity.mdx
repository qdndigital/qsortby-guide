Once a collection is sorting, the Activity tab tells you whether it's working. It compares click-through before and after qSortBy took over, shows the uplift, and keeps a log of every sort run.

## 1. Open the Activity tab

![Open the Activity tab](/assets/collection-activity/qsortby-collection-activity-step-01.png)

Get there from **Left menu → Collections → open a collection → the Activity tab**. This is the collection's report card — proof of what the sorting has done, in one view.

## 2. Compare CTR and read the uplift

![Compare CTR and read the uplift](/assets/collection-activity/qsortby-collection-activity-step-02.png)

The top of the tab shows **CTR before** qSortBy sorted the collection next to **CTR now**, with the **uplift** between them. A positive uplift means the sort rule is putting the products shoppers click on higher up.

<Callout type="tip" title="Tip">
Give a new sort rule a few days of traffic before judging the uplift — early numbers move around.
</Callout>

## 3. Review the run history

![Review the run history](/assets/collection-activity/qsortby-collection-activity-step-03.png)

Below the metrics, the **run history** table logs every sort — when it ran, what triggered it, and how the order changed. Use it to confirm the collection is re-sorting on the cadence you set and to trace any surprising change back to a specific run.

The Activity tab closes the loop: it shows the CTR before and after, the uplift qSortBy produced, and a full run history so you can trust that sorting is doing its job.
