Before a segment rule goes live, review exactly what it will do. qSortBy shows each group's reach, a live product preview, and a plain-English summary of the whole rule. This guide covers reviewing an existing rule and publishing it.

## 1. Review the rule and its reach

![Review the rule and its reach](/assets/publish-and-manage/qsortby-segment-publish-step-01.png)

Open **Segment Rules** from the left menu, then select any rule to review it. Each shopper group shows what it **ranks by** and its **reach** — an estimate of the share of shoppers it covers. Here, **Returning customers** reaches about 34% and **Everyone else** covers the remaining 66%. Reach helps you sanity-check that your groups are aimed where you intend.

## 2. Check the live preview and plain-words summary

![Check the live preview and plain-words summary](/assets/publish-and-manage/qsortby-segment-publish-step-02.png)

The **Preview** panel does a dry run, showing the product order each group would see side by side. Below it, **In plain words** restates the entire rule as sentences — *Returning customers → Repeat purchase first, then Favorite category affinity; Everyone else → Top sellers first, then New arrivals* — so you can confirm the logic at a glance before going live.

<Callout type="tip" title="Tip">
The preview is a dry run — nothing changes on your storefront until the rule is published.
</Callout>

## 3. Publish the rule

![Publish the rule](/assets/publish-and-manage/qsortby-segment-publish-step-03.png)

When the reach and preview look right, publish the rule to make it live. **Only one segment rule is published at a time** — publishing a rule automatically takes over from whichever was live before, so there's never a conflict. An already-live rule shows **Unpublish**, which steps it back down to a safe Draft.

That's the review-and-publish loop: check each group's reach, confirm the order in Preview, read the In plain words summary, then publish. Because only one rule is live at a time, going live with a new rule cleanly replaces the previous one.
